# 페이앱 결제링크 상품 등록표

가격은 판매가표(2026-11-23 기준) 그대로예요. 시세가 바뀌면 사이트와 결제링크를 같이 고쳐주세요.

## 모든 상품 공통

| 항목 | 입력 |
|---|---|
| 상점명 | 판매자명 사용 체크 |
| 구매자 입력 허용 (상품명, 가격) | 둘 다 체크 안 함 |
| 과세 구분 | 과세 |
| 이미지 | 직접 찍은 카드 앞면 사진 |
| 주소요청 | 주소요청 |
| 결제메모표시 | 결제메모표시 |
| 결제수단 | 지금 체크된 그대로 |

**결제완료 내용** (모든 상품 같음)

```
결제해 주셔서 감사합니다.
카드는 슬리브와 탑로더에 넣어 입력하신 주소로 보내드리고, 발송하면 운송장 번호를 알려드려요.
문의는 인스타 DM이나 오픈카톡으로 주세요.
```

## 따로 만들 링크 2개

**택배비**
- 상품명: `택배비`
- 가격: 사장님이 정한 택배비 (1,000원 이상)
- 상세내용: `카드 주문 1건당 한 번만 결제해 주세요. 같은 날 여러 장을 사셔도 한 번이면 돼요.`
- 주소요청: 요청안함 (카드 링크에서 이미 받음)

**여러 장 한 번에 결제** (사이트 구매 목록 합계용)
- 상품명: `카드 묶음 주문`
- 가격: 비워두고 **구매자 입력 허용** 체크
- 상세내용: `사이트 구매 목록의 합계 금액을 입력해 주세요. 결제메모에 복사한 목록을 붙여넣어 주시면 확인 후 보내드려요.`
- 주소요청: 주소요청 / 결제메모표시: 결제메모표시
