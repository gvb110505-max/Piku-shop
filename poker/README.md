# ♠ PIKU POKER

같은 와이파이에 연결된 친구들과 각자 휴대폰으로 즐기는 **멀티플레이 텍사스 홀덤**.
앱 설치 없이 브라우저로 접속하고, 한 사람의 컴퓨터가 테이블(서버) 역할을 합니다.

- 설치할 패키지 없음 — Node.js만 있으면 바로 실행
- 휴대폰 세로/가로, 태블릿, PC 모두 지원 (TV에 띄워 관전 화면으로도 사용 가능)
- 카메라로 QR 코드만 찍으면 바로 입장

## 실행 방법

1. **호스트 컴퓨터**에 [Node.js](https://nodejs.org) (LTS, 18 이상)를 설치합니다.
2. `poker` 폴더에서 실행합니다.
   - Windows: `start-windows.bat` 더블클릭
   - Mac: `start-mac.command` 더블클릭 (처음엔 우클릭 → 열기)
   - 터미널: `cd poker && node server.js`
3. 터미널에 나오는 주소(예: `http://192.168.0.12:3000`)나 **QR 코드**로 친구들이 접속합니다.
   게임 안의 **초대(QR) 버튼**으로도 언제든 주소를 띄울 수 있어요.
4. 닉네임/아바타를 정하고 빈 자리(**+**)를 누르면 착석.
   2명 이상 앉으면 **호스트(가장 먼저 들어온 사람)** 가 `게임 시작`을 누릅니다.

> 포트를 바꾸려면 `PORT=4000 node server.js` (Windows: `set PORT=4000 && node server.js`)

## 게임 기능

| | |
|---|---|
| 규칙 | 노리밋 텍사스 홀덤, 최대 9인. 블라인드·딜러 버튼 자동 이동, 헤즈업 규칙 |
| 베팅 | 폴드 / 체크 / 콜 / 벳·레이즈 (½팟·¾팟·팟·올인 프리셋, 슬라이더, 직접 입력) |
| 정확한 규칙 처리 | 사이드팟, 언콜 벳 반환, 미완성 올인 레이즈, 스플릿 팟과 홀수 칩 |
| 올인 쇼다운 | 카드 공개 후 한 장씩 오픈되며 **실시간 승률(%)** 표시 |
| 미리 선택 | 내 차례 전에 `체크/폴드`, `콜`, `콜 애니` 예약 |
| 타이머 | 턴 제한 시간 링, 시간 초과 시 자동 체크/폴드, 2회 연속이면 자리비움 |
| 재접속 | 새로고침하거나 와이파이가 끊겨도 같은 자리·같은 카드로 자동 복귀 |
| 소셜 | 채팅(말풍선), 이모티콘 리액션, 핸드 기록, 순위표(손익) |
| 호스트 | 시작 칩, 블라인드, 블라인드 자동 상승, 턴 시간, 최대 인원, 리바이 허용, 일시정지, 내보내기, 호스트 넘기기, 새 게임 |
| 연출 | 카드 딜링/플립, 칩 이동, 승자 하이라이트, 효과음(직접 합성), 진동 |
| 개인 설정 | 사운드, 4색 카드, 테이블 색상 5종 |

PC 단축키: `F` 폴드 · `C`/`Space` 체크·콜 · `R` 레이즈 · `↑↓` 금액 · `Enter` 확정 · `Esc` 닫기

## 접속이 안 될 때

- **같은 와이파이인지** 확인하세요. 휴대폰이 LTE/5G 로 접속 중이면 안 됩니다.
- **방화벽**: 처음 실행할 때 Windows가 묻는 창에서 *개인 네트워크 허용* 을 눌러주세요.
  Mac은 *시스템 설정 → 네트워크 → 방화벽* 에서 node 의 수신 연결을 허용합니다.
- 카페·회사 **게스트 와이파이**는 기기 간 통신을 막아두는 경우가 많습니다(AP 격리).
  이럴 땐 휴대폰 핫스팟에 모두 연결하면 됩니다.
- 터미널에 주소가 여러 개 나오면 다른 주소로도 시도해 보세요.

게임 상태는 서버(호스트 컴퓨터) 메모리에만 있으므로, 서버를 끄면 칩과 기록이 초기화됩니다.

## 구조

```
poker/
├─ server.js          HTTP + WebSocket 서버, LAN 주소/QR 출력
├─ lib/
│  ├─ game.js         홀덤 테이블 엔진 (베팅 규칙, 사이드팟, 타이머, 재접속)
│  ├─ poker.js        카드, 셔플(crypto), 7장 족보 판정, 승률 계산
│  ├─ ws.js           의존성 없는 WebSocket 구현
│  └─ qr.js           의존성 없는 QR 코드 생성기
├─ public/            클라이언트 (HTML/CSS/JS 모듈)
└─ test/              족보 판정 · 엔진 퍼징 테스트
```

카드 섞기는 서버에서 `crypto.randomInt` 로 하고, 각 플레이어에게는 **자기 카드만** 전송합니다
(쇼다운 전까지 다른 사람의 카드는 브라우저에 아예 전달되지 않음).

테스트: `npm test`
